# AI 智能学习助手

按照设计性实验要求逐步开发的 Python 学习项目。目前处于控制台原型阶段。

## 运行

需要 Python 3.8 或更新版本，当前仅使用标准库，无需安装第三方依赖。

```powershell
python main.py
```

输入问题后按回车，输入“退出”结束程序。

## 当前功能

- 连续输入问题，获得明确标注的模拟回答。
- 将用户问题和模拟回答保存到本地 JSON 文件。
- 重新启动时恢复聊天历史。
- 读取并检查本地配置。
- 对记录损坏、配置错误和保存失败给出提示。

当前没有接入真实 AI API，也没有实现图形界面、流式输出和多会话管理。

## 文件说明

- `main.py`：程序入口、聊天记录读写和控制台交互。
- `ai_client.py`：模拟回答，后续接入真实 API。
- `config.py`：配置读取和校验。
- `config.example.json`：不包含真实密钥的配置示例。

## 本地配置

复制 `config.example.json` 并将副本命名为 `config.json`。
当前请保持 `mode` 为 `mock`，真实 API 请求将在后续实现。

真实密钥只放在本地 `config.json` 中，不要写入示例文件或代码。
`.gitignore` 已排除本地配置、聊天记录和 Python 缓存。
