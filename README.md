# AI 智能学习助手

按照设计性实验要求逐步开发的 Python 学习项目。目前支持桌面聊天窗口和控制台入口。

## 运行

需要 Python 3.8 或更新版本，当前仅使用标准库，无需安装第三方依赖。

```powershell
python main.py
```

输入问题后按回车，输入“退出”结束程序。

启动桌面窗口（需要 Python 环境包含 tkinter）：

```powershell
python gui.py
```

点击发送或按 Ctrl+Enter 提问，Enter 换行。后台线程接收回答，主线程通过队列定时更新窗口。
生成期间可以编辑输入，但不能重复发送；关闭时会提示未完成回答将被丢弃。

## 当前功能

窗口顶部可选择会话主题，点击“主题统计”查看各主题提问数量。
分类以整个会话为单位，修改主题会重新归类该会话的全部历史问题。
旧会话默认为“未分类”；统计现存用户消息（包括请求失败的问题），删除会话后数量减少。
统计窗口显示主题柱状图和累计窗口使用时长，不调用模型。尚未实现自动分类。
时长从本版本开始累计，包含窗口打开期间的等待及空闲时间；不代表有效学习时间。
每分钟及正常保存时写入本地数据，异常退出可能丢失最后一次保存后的时长。
统计页为打开时的快照，关闭后重新打开可刷新。控制台使用时间不计入。

- 连续输入问题，获得明确标注的模拟回答。
- 调用兼容 Chat Completions 的 HTTPS 接口，边接收边显示回答；保留普通请求函数。
- 将用户问题和完整回答保存到本地 JSON 文件。
- 流式请求中断时提示错误，不将部分回答保存为完整 AI 消息。
- 重新启动时恢复聊天历史。
- 读取并检查本地配置。
- 对记录损坏、配置错误和保存失败给出提示。

窗口支持新建、切换会话，各会话独立保存历史，并恢复上次选中项。生成期间禁止切换会话。
输入草稿在切换时保留在内存中，关闭后不会保留。
支持重命名和删除当前会话。重命名保留消息和会话 ID；删除需要确认，且无法撤销。
删除后切换到相邻会话；删除最后一个会话后，自动建立空的默认会话。
生成回答期间禁用重命名和删除，避免操作冲突。
用户已验证窗口聊天正常；多会话的新建、切换、隔离和恢复已通过模拟测试。

窗口使用 `sessions.json`。首次启动新版窗口时，如果该文件不存在，会将旧的
`chat_history.json` 迁移为“默认会话”，并保留旧文件。控制台仍使用旧文件，
两种入口的后续历史不会同步，建议使用窗口版。请勿同时打开多个程序实例。

## 文件说明

左侧“收藏问答”可从当前会话选择完整问答并预览、收藏；“查看收藏夹”可查看或移除收藏。
同一问答不重复收藏。收藏以独立副本保存在已忽略的 `sessions.json` 中，
删除原会话后仍保留；移除收藏不会改变原会话。生成期间请等待回答完成后再收藏。

输入学习内容后，选择“知识点讲解”“学习计划”或“错题分析”，点击“应用到输入框”。
模板只整理提示词，不会自动发送；可以编辑后再点击发送。实际回答由当前模型生成。

窗口左侧的“导出会话”可将当前会话保存为 UTF-8 的 TXT 或 Markdown 文件。
仅导出会话名称和已保存的消息，不包含配置或草稿；生成期间禁止导出。
建议导出到项目外，或放在已忽略的 `exports/` 文件夹，避免将私人对话提交到仓库。

- `main.py`：程序入口、聊天记录读写和控制台交互。
- `gui.py`：tkinter 桌面窗口、后台线程和队列更新。
- `session_manager.py`：多会话数据管理、校验和旧历史迁移。
- `exporter.py`：将当前会话导出为 TXT 或 Markdown。
- `prompt_templates.py`：学习提示词模板及内容填充。
- `ai_client.py`：模拟回答和真实 API 请求。
- `config.py`：配置集合读取、兼容转换、校验和保存。
- `settings_dialog.py`：多套 API 配置的编辑与切换窗口。
- `config.example.json`：不包含真实密钥的配置示例。

## 本地配置

窗口左侧“API 配置”支持新建、删除和切换多套命名配置。
切换时保留表单修改；点击“保存并应用”后统一写入本地，下一次提问生效。
取消或关闭配置窗口会放弃本次全部修改。至少保留一套配置。
密钥默认遮挡，可以选择显示；遮挡不等于加密，配置在本地以明文保存。
生成期间不能修改配置。旧版单套配置自动识别，首次保存时转为配置集合。
集合中的 `profiles` 保存各套参数，`active_profile` 记录当前配置名称。
控制台同样读取当前配置；所有配置的密钥仍只保存在本地 `config.json`。

复制 `config.example.json` 并将副本命名为 `config.json`。
模拟模式将 `mode` 设为 `mock`。真实模式设为 `api`，并填写服务商的
`api_key`、`base_url` 和 `model`。`base_url` 使用 HTTPS 基础地址，
不要包含 `/chat/completions`，程序会自动补上该路径。
`timeout` 为请求超时秒数。控制台等待回答；桌面窗口使用后台线程接收回答。
回答以接口返回的文本片段陆续显示，不保证每次只出现一个字。
只显示回答正文；模型先思考时，正文出现前可能需要等待。
真实模式会将当前会话历史发送到所配置的服务商，包括此前保存的模拟消息。

真实密钥只放在本地 `config.json` 中，不要写入示例文件或代码。
`.gitignore` 已排除本地配置、聊天记录和 Python 缓存。


测试使用临时文件和模拟网络，不读取真实密钥或聊天记录。
